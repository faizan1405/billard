# Vandenberg & Co. — Luxury Billiards Atelier

A modern, high-end e-commerce homepage crafted for a luxury billiards and pool equipment brand.

Built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**.

---

## ✨ Features

- **Full-Screen Cinematic Hero**: Dramatic spotlighting over green felt, parallax motion, specs bar, and dual CTAs.
- **Asymmetric Editorial Categories**: Large photography cards with slow hover zoom for Pool Tables, Cues, Balls, and Accessories.
- **Featured Equipment**: Interactive product cards with secondary image hover switch, quick add to bag, and wishlist toggles.
- **Signature Pool Table Section**: Storytelling showcase with live interactive **Cloth & Wood Finish Studio**.
- **Interactive Engineering Hotspots**: Pulsating radar pins across the table surface displaying microscopic specs and tolerances.
- **Shop The Game Showcase**: Three-stage ritual curation for **PLAY**, **UPGRADE**, and **MAINTAIN**.
- **Atelier Heritage Story**: Master player editorial layout with 130+ years history.
- **Why Choose Us**: Four minimal luxury pillars with Roman numbering and gold accents.
- **Penthouse Lifestyle Banner**: Panoramic full-width game room centerpiece banner.
- **Client Testimonials Carousel**: Reviews from verified owners in New Delhi, London, and Mumbai.
- **Interactive E-Commerce Layer**:
  - Slideout Shopping Bag Drawer with white-glove installation progress meter.
  - Private Wishlist Drawer with "Move to Bag" action.
  - Product Quick View Modal with multi-angle gallery and specs.
  - Spotlight Command Search with live query filtering and trending tags.
  - Floating Toast Notifications.
- **100% Local High-Resolution Assets**: No external CDN dependencies; all photos load offline and instantly.

---

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the homepage.

### 3. Build for production
```bash
npm run build
```

## 🌐 Deploy with Vercel

1. Push this repository to GitHub (`billard`).
2. Go to [vercel.com](https://vercel.com) and import the `billard` repository.
3. Framework Preset: **Vite**
4. Root Directory: `./`
5. Click **Deploy**.
